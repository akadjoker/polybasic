# Dead Field assets

Used by `examples/zombies.pb`. Most files come from the author's other
engine's demo (Nord, `assets/siege`), where they were converted from files
already on the author's disk. Where a source states a licence it is given;
the others are marked "not confirmed" and need checking before the demo is
published widely.

| File | Source | Author and licence |
|---|---|---|
| `zombie.glb` | A Mixamo character ("Yaku J Ignite") with Mixamo animations (idle, walk, run, attack, hit, death, dying, scream, rise) merged into one file with Blender; the root motion of walk, run and hit was removed. | Adobe Mixamo. Free to use in projects; the raw files may not be redistributed as an asset pack. |
| `gun/` | "Doom 2016 - Plasma Gun", https://sketchfab.com/3d-models/doom-2016-plasma-gun-d9777005def242cd958cf822f3902a1e | Ilia_Tun, CC BY 4.0. The design itself belongs to id Software. Only the colour texture is kept (normal and metal maps are not used here). |
| `bonfire/` | "LowPoly bonfire", https://sketchfab.com/3d-models/lowpoly-bonfire-6c0ca6f74536435ab7d54eb17a1155bb | LEX_GFX, CC BY 4.0. Only the colour texture is kept. |
| `barrel.glb`, `barrel_d.jpg` | the barrel of an FPS demo on the author's disk | not confirmed |
| `crate_d.jpg` | the crate of a sample from another engine | not confirmed |
| `ground_d.jpg`, `rock_d.jpg` | landscape textures from the author's other engine's examples | not confirmed |
| `fire.jpg`, `explosion.jpg`, `flash.jpg`, `glow.jpg`, `blood.png`, `ring.png`, `smoke.png` | particle textures from the same examples | not confirmed |
| `*.wav` | sounds from Blitz3D samples and Kinetix2D | not confirmed |

Textures were resized to 1024 or 2048 pixels and saved as JPEG.
