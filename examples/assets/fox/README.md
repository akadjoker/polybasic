# Fox

`fox.glb` is the Fox from the Khronos glTF Sample Assets
(https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/Fox):

- Model: PixelMannen, CC0 1.0.
- Rigging and animation: tomkranis, CC BY 4.0
  (https://creativecommons.org/licenses/by/4.0/).
- glTF conversion: @AsoboStudio and @scurest, CC BY 4.0.

It has one skinned mesh with 24 joints and three animations: Survey, Walk
and Run.
